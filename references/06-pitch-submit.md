# P6 路演与提交 — 故事、Q&A、合规

> 目标:slides + 演示 + Q&A卡 + 提交完成。时间盒 10%。**同样水平的作品,路演好坏可以差两个奖级。**

## 故事弧(3分钟标准结构,按分钟切)

| 时间 | 内容 | 要点 |
|---|---|---|
| 0:00-0:20 | 钩子 | 一个具体的"人的瞬间"(痛点场景/反差数据/现场演示预告)。**禁止**以"大家好我们是XX队"开场超过5秒 |
| 0:20-0:50 | 问题+为什么是现在 | 谁在痛、现在怎么硬扛、什么变了(why-now) |
| 0:50-2:20 | **现场演示** | 演示脚本逐场景走,magic moment 处闭嘴让画面说话 |
| 2:20-2:45 | 技术亮点 | 评委能懂的 1-2 个硬点(为什么难/为什么快/为什么准),一张架构图封顶 |
| 2:45-3:00 | 愿景收尾 | "如果它真的被用起来"一句话 + 团队一句 + 致谢 |

**现场生成环节(TechCrunch 四步法之外的杀手锏)**:演示脚本里留一个"评委给输入"的场景——请评委/观众随口出一个输入(一句谣言/一封邮件/一张照片),产品现场跑真链路出结果。"不可复制的 wow":其他队都是排练好的,你是现场应答。

**评审物理结构适配**(MLH 系现场赛):每队只有 4 分钟(2 演示+1 问答+1 评委走路),每评委报 top3 stack ranking——开场 30 秒没有钩子就输了;URL/产品名每页幻灯片和口头反复出现。提交的 2 分钟视频必须是"demo 不是 presentation"(录屏实拍优先,禁幻灯片朗读)。MLH 评委被提醒 "focus on learning over profit"——学生赛别把商业神话讲上天,把"我们学到了什么"讲出来(learning 是 MLH 四维正式评分项)。

- **排练 3 遍起**:第1遍照稿,第2遍脱稿掐表,第3遍模拟故障(突然要求"跳过X直接讲Y")。
- 语速检查:写满的稿子念不完是常态;删到能在 2:40 说完,留缓冲。
- 团队分工:主讲 1 人,演示操作 1 人(分工固定,提前排练交接口令)。

## Slides 纪律

- 页数 ≤8:封面 / 问题 / why-now / (演示全屏,不用slide) / 技术架构 / 市场/差异化 / 愿景 / 致谢+二维码
- 每页 ≤20 个词的大字 + 一张图;slides 是背景板,不是提词器
- 用 AI 生成初稿可以,但数据/竞品页必须人工核对来源(评委追问)

## Q&A 卡(赛前准备 ≥10 问)

必备六类:
1. 数据来源类:"你这市场数字/用户痛点哪来的?"(答:02-market.md 的来源清单)
2. 技术选型类:"为什么用X不用Y?"(答:速度优先+适配,承认 trade-off)
3. 与大厂竞品类:"XX厂做了你怎么办?"(答:差异化声明+场景纵深)
4. 边界类:"离了 demo 这东西还成立吗?"(答:Must→Should 的路线图)
5. 落地类:"商业模式/谁来用/怎么推广?"(答:先答第一个用户从哪来,别扯五年规划)
6. 诚实类:"这个功能是真的吗?"(答:现场可跑的是真的,预置数据如实说明——**演示用了种子数据要主动说,被发现没说是诚信问题**)

每问准备 30 秒答案,写进 05-pitch/qa.md,赛前互相抽问。

## 提交合规(SUBMISSION.md 逐项打勾)

- [ ] 平台表单全部字段(截图文案先写在本地文档,避免临时组织语言)
- [ ] demo 视频:**M4 已录成**(不是提交晚上的事);时长/格式/分辨率按官方要求;首 10 秒有钩子;若是"demo 不是 presentation"(MLH 系硬要求);上传后**用无痕浏览器点开验证可播**
- [ ] repo:README(5分钟跑通指南)/ LICENSE / 种子数据 / .env.example(**绝不提交真实 key**)
- [ ] 开源/AI 使用披露:按官方要求如实填写(用 P3 的草稿核对终稿)
- [ ] **口径终检**:种子条数/数据源数量/耗时数字在 QA卡、slides、demo-script、提交页四处一致(grep 数量词交叉核对)
- [ ] 截止时间换算成本地时区,提前 2 小时提交(平台最后时刻必堵)
- [ ] 团队信息/成员页/材料一致性(名字拼写统一)

## 提交后 30 分钟

- 检查作品页在平台上的最终渲染(图片是否挂了/视频封面)
- 准备公开链接(部署 demo 到 Vercel/Netlify,评委真的会点)
- 休息。路演前睡眠的作用大于任何加班。

## 验收门
- [ ] 排练 ≥3 遍,总时长 ≤规定
- [ ] Q&A 卡 ≥10 问且互相抽问过
- [ ] SUBMISSION.md 全部打勾 + 提前 2h 提交
- [ ] 公开可访问的部署链接可用
