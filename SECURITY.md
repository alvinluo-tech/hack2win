# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest version of `hack2win`:

| Version | Supported          |
| ------- | ------------------ |
| v14.x   | :white_check_mark: |
| < v14.0 | :x:                |

## Reporting a Vulnerability

We take the security of autonomous development environments and credential management seriously.

If you discover a security vulnerability (such as secret leak patterns in CLI audit scripts, unsanitized terminal inputs, or command injection flaws in automation scripts):

1. **Do not create a public issue.**
2. Email [luoyaosheng123@gmail.com](mailto:luoyaosheng123@gmail.com) with the subject `[SECURITY] hack2win Vulnerability Report`.
3. Include:
   - Description of the vulnerability
   - Proof-of-concept steps or exploit scenario
   - Affected CLI scripts or documentation rules
4. We will acknowledge receipt within 48 hours and coordinate a responsible disclosure timeline with you.
